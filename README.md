# 救急欠員の代替候補

研修医の当直・ローテ表(Excel .xlsx / .xlsm)を読み込み、休む研修医と期間を入れると、空く救急の枠(早番・日勤・準夜・深夜)と当直ごとに、代わりに入れる研修医の候補を一覧にする静的Webアプリです。

- Excelはブラウザの中だけで読み込みます。サーバーへの送信・保存はありません。
- ページ自体に研修医のデータは含まれていません(初期表示は架空のサンプル)。
- ビルド不要。`index.html` と `vendor/xlsx.full.min.js`(SheetJS 0.18.5, Apache-2.0)だけで動きます。

## デプロイ
Vercel でこのリポジトリをインポートし、Framework Preset は「Other」、Build Command・Output Directory は空のままでデプロイします。

## 判定ルール
画面下部「判定のしかた」を参照。最終判断は救急科・チーフ・各科が行います。
